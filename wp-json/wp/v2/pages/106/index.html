Futurhythmachine is a Pure Data patch made for the manipulation of breakbeat drum loops. It features parameters that include sample slicing, envelope shaping, BPM adjust, built in reverb, built in granular synthesis, a waveshaper\/distortion module and filters, as well as randomisation of pitch, slice reverse, stutter, glide and mute.<\/p>\n\n\n\n
